## 统一社交媒体图标实现方式

### 需要创建的文件（4个）

**1. 创建 `layouts/partials/icons/bilibili.html`**
- 从 `static/images/icons/bilibili.svg` 提取 SVG 内容
- 转换为内联 SVG 格式
- 所有 `<path>` 添加 `fill="currentColor"`
- 添加 `<title>` 元素：`<title id="icon-bilibili-title">Bilibili</title>`

**2. 创建 `layouts/partials/icons/shipinhao.html`**
- 从 `static/images/icons/shipinhao.svg` 提取 SVG 内容
- 转换为内联 SVG 格式
- 所有 `<path>` 添加 `fill="currentColor"`
- 添加 `<title>` 元素：`<title id="icon-shipinhao-title">视频号</title>`

**3. 创建 `layouts/partials/icons/email.html`**
- 从 `static/images/icons/email.svg` 提取 SVG 内容
- 转换为内联 SVG 格式
- 所有 `<path>` 添加 `fill="currentColor"`
- 添加 `<title>` 元素：`<title id="icon-email-title">Email</title>`

**4. 创建 `layouts/partials/icons/phone.html`**
- 从 `static/images/icons/phone.svg` 提取 SVG 内容
- 转换为内联 SVG 格式
- 将 `fill="#333333"` 改为 `fill="currentColor"`
- 添加 `<title>` 元素：`<title id="icon-phone-title">Phone</title>`

### 内联 SVG 格式模板

```html
<svg class="social-icon" viewBox="0 0 1024 1024" xmlns="http://www.w3.org/2000/svg" role="img" aria-labelledby="icon-{id}-title">
  <title id="icon-{id}-title">{名称}</title>
  <path d="..." fill="currentColor" />
</svg>
```

### 修改后的效果

- ✅ 所有 9 个社交媒体图标统一使用内联 SVG
- ✅ 统一使用 `fill="currentColor"` 继承 CSS 颜色
- ✅ 统一显示为灰色 `#6c757d`，悬停蓝色 `#00a6ff`
- ✅ 统一大小为 20px × 20px
- ✅ 便于后期维护
