# 修改新闻时间显示格式为中文

## 需求分析

**当前格式：** 英文日期（如 "January 2, 2006"）
**目标格式：** 中文日期（如 "2025年9月23日09:00"）

## 实施方案

**修改文件：** `layouts/news/single.html`
**修改位置：** 第10行
**当前代码：**
```html
<p><span>{{ .PublishDate.Format "January 2, 2006" }}</span> in
```

**修改为：**
```html
<p><span>{{ .PublishDate.Format "2006年1月2日 15:04" }}</span> in
```

或者更简洁的格式（不带时间）：
```html
<p><span>{{ .PublishDate.Format "2006年1月2日" }}</span> in
```

## 格式说明

Hugo的 `Format` 方法支持中文格式：
- `2006年1月2日` - 年月日格式
- `2006年1月2日 15:04` - 年月日时分格式
- `2006年1月2日 15:04:05` - 年月日时分秒格式

## 实施步骤

1. 修改 `layouts/news/single.html` 第10行的日期格式
2. 验证生成的HTML是否为中文格式
3. 在浏览器中查看显示效果
