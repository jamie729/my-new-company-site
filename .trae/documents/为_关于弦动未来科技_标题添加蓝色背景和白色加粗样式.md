# 为"关于弦动未来科技"标题添加样式的方案

## 需求分析

**目标元素：** "关于弦动未来科技"（第23行的三级标题）
**样式要求：**
- 蓝色背景底色
- 字体为白色且加粗
- 文本内容居中对齐
- 不影响页面其他内容的布局和样式

## 实施方案

**方案：在Markdown中使用HTML标签添加特定类名**

修改 `content/news/2025wmc/index.md` 第23行：
- 从 `### 关于弦动未来科技` 改为 `<h3 class="company-info">关于弦动未来科技</h3>`
- 这样可以精确控制样式，不影响其他h3标题

**在custom.css中添加样式：**
```css
.post-body h3.company-info {
    background-color: #007bff;
    color: #ffffff;
    font-weight: bold;
    text-align: center;
    padding: 12px 20px;
    border-radius: 6px;
    margin: 30px 0;
    box-shadow: 0 2px 8px rgba(0,123,255,0.15);
}
```

## 优势

1. **精确控制** - 只影响指定的标题
2. **不破坏其他样式** - 其他h3标题保持原样
3. **易于维护** - 样式集中在CSS文件中
4. **响应式友好** - 可以添加媒体查询适配移动端

## 实施步骤

1. 修改 `content/news/2025wmc/index.md` 第23行
2. 在 `static/css/custom.css` 中添加样式
3. 在浏览器中测试显示效果
